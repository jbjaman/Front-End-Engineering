// HTML

HyperText Markup Language. এটি webpage-এর structure তৈরি করে।

// Semantic HTML

Semantic HTML এমন HTML elements ব্যবহার করে যেগুলোর অর্থ ও উদ্দেশ্য পরিষ্কার।

<header>  ->	Page বা section-এর header
<nav> ->	Navigation links
<main>	-> Page-এর প্রধান content
<section>	-> সম্পর্কিত content-এর section
<article> ->	স্বতন্ত্র content
<footer> ->	Footer content
<button> -> কোনো action সম্পাদন
<form> -> User input জমা দেওয়া

important কারণ: 

Code সহজে বোঝা যায়।
Screen reader content-এর structure ভালোভাবে বুঝতে পারে।
Keyboard navigation ও accessibility উন্নত করা সহজ হয়।
Maintainability বাড়ে।

Semantic HTML uses elements that describe the meaning and purpose of content, improving code readability, accessibility, and maintainability.

div একটি generic container। এর নিজস্ব কোনো নির্দিষ্ট semantic meaning নেই।

// htmml forms

function LoginForm() {
  return (
    <form>
      <label htmlFor="email">Email</label>
      <input
        id="email"
        name="email"
        type="email"
        autoComplete="email"
        required
      />

      <label htmlFor="password">Password</label>
      <input
        id="password"
        name="password"
        type="password"
        autoComplete="current-password"
        required
      />

      <button type="submit">Log in</button>
    </form>
  );
}

label-এর htmlFor সংশ্লিষ্ট input-এর id-এর সঙ্গে মেলে।
type="email" উপযুক্ত browser-level validation দেয়।
required field খালি থাকলে submission আটকাতে সাহায্য করে।
type="submit" form submit করে।
React-এ onSubmit দিয়ে submission handle করা যায়।
