1. React কী ??

React হলো একটি js library for building user interfaces.
React ব্যবহার করে আমরা UI-কে ছোট ছোট reusable component-এ ভাগ করে তৈরি করি।

Dashboard
│
├── Navbar
├── Sidebar
├── UserStats
├── UserTable
│   ├── UserRow
│   ├── UserRow
│   └── UserRow
└── Footer

প্রতিটি অংশ একটি component হতে পারে।

React আমাদের UI কে declarative and component based ভাবে তৈরী করতে সাহায্য করে.

মূল সুবিধা:

- Reusable components
- Declarative UI
- Efficient UI updates
- State-driven rendering
- Large application maintainability
- Ecosystem
- React Router, testing libraries, data-fetching libraries ইত্যাদির সাথে কাজ করা যায় 

React helps us build maintainable user interfaces using reusable components and declarative, state-driven rendering.
