Props = properties
Props হলো parent component থেকে child component-এ data পাঠানোর mechanism

parent:

function App(){
    return <UserCard name="Jubayer"/>
}

child:

function UserCard ({name}){
    return <h2>{name}</h2>
}

rules: Props are read-only. Child component props পরিবর্তন করবে না। Props-এর data parent থেকে আসে।

function UserCard({ name, age, role }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>Age: {age}</p>
      <p>Role: {role}</p>
    </div>
  );
}

multiple props থাকতে পারে
